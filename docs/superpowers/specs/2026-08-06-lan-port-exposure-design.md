# Доступ Open WebUI из домашней сети — дизайн

## Цель

Сделать Open WebUI, работающий в контейнере `webui`, доступным по TCP-порту 8080 как с хоста, так и с устройств домашней локальной сети.

## Границы

Изменяется только публикация порта `webui` в `docker-compose.yml` и инструкция по подключению в `README.md`. Proxy-сервис, его API, аутентификация Google Cloud, контейнерная сеть и маршрутизация на роутере не меняются.

## Решение

Заменить публикацию Docker-порта:

```yaml
ports:
  - "127.0.0.1:8080:8080"
```

на:

```yaml
ports:
  - "0.0.0.0:8080:8080"
```

Docker будет принимать TCP-соединения на порту 8080 со всех IPv4-интерфейсов хоста и передавать их в порт 8080 контейнера `webui`. Локальный доступ по `http://localhost:8080` сохраняется. В LAN пользователи подключаются по `http://<LAN-IP-хоста>:8080`.

## Безопасность

Изменение открывает интерфейс Open WebUI для устройств, способных достигнуть сетевых интерфейсов хоста, включая VPN-интерфейсы. Оно само по себе не открывает порт в интернете: для этого нужен отдельный проброс порта на маршрутизаторе. Хостовый firewall, если включён, должен разрешать TCP/8080 только для доверенной домашней подсети.

## Проверка

Проверить итоговую Compose-конфигурацию и запустить стек. С хоста запрос к `http://localhost:8080` должен работать; с другого устройства домашней сети — запрос к `http://<LAN-IP-хоста>:8080`.
